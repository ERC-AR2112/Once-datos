# Once-Datos

Repositorio con los códigos, trabajos de investigación y bases de datos realizados por Once Datos para Once Noticias.

Este repositorio se divide en carpetas según diferentes temas de interés. Las principales secciones son: 
- Temas nacionales
- Temas internacionales
- Proyectos Dirección general

<img width="917" height="396" alt="image" src="https://github.com/user-attachments/assets/5fc9b7cb-423c-439c-911e-2d5743dc2693" />

## Instrucciones de uso

1. Al hacer clic en la carpeta de interés, podrá ingresar a su contenido. Dentro encontrará los diversos temas que se han trabajado en cada sección.

<img width="1299" height="349" alt="image" src="https://github.com/user-attachments/assets/4ce5c567-08dc-4217-a395-07aa59dbd41e" />

2. Dentro de cada tema se encontrarán diversas carpetas, cada una para cada trabajo de investigación específico que se ha realizado.

<img width="1293" height="340" alt="image" src="https://github.com/user-attachments/assets/154b60c2-1666-44ed-a0de-587cc0300915" />

3. Al ingresar al tema de interés, encontrará el trabajo escrito y un link para su acceso al documento de trabajo colaborativo.

<img width="700" height="235" alt="image" src="https://github.com/user-attachments/assets/51c81d78-cabf-4a61-9988-dad47b853c1d" /> 

4. Los documentos de trabajo colaborativo están regularmente en Google Docs, y cualquier persona que acceda desde el enlace puede editar.

<img width="950" height="470" alt="image" src="https://github.com/user-attachments/assets/0c79fa87-daa3-4e80-bb1a-6f3a6c08a789" />

5. En las carpetas que acompañan el documento colaborativo, encontrará el código que se utilizó para realizar el análisis (usualmente en R), así como las bases de datos.
   
<img width="1571" height="835" alt="image" src="https://github.com/user-attachments/assets/59241790-3bba-4301-9f9c-7bd26a23ef26" />

6. En caso de que la base de datos sea muy grande y no pueda colocarse en el sitio de GitHub, se coloca un enlace que dirige a un espacio de Google Drive donde se encuentra. Para descargarla, solo debe ingresar al link y descargar la base.
   
<img width="1564" height="640" alt="image" src="https://github.com/user-attachments/assets/a6f54e31-5444-4286-825c-2f0424e27ca1" />

7. Si desea ingresar un documento a alguna carpeta, puede hacerlo desde el botón Add file.

<img width="700" height="221" alt="image" src="https://github.com/user-attachments/assets/bdb436a9-4c71-49a5-9795-734930c028da" />

Al hacer clic en este botón, se desplegará un menú con dos opciones:
- Create new file
- Upload files

<img width="318" height="102" alt="image" src="https://github.com/user-attachments/assets/011be3d7-1839-4d51-b2dd-8f4af6f8e565" />

La opción "Upload files" permite subir cualquier archivo que se desee compartir.
La opción "Create new file" permite crear un nuevo archivo de texto, ya sea código o texto plano. Este usualmente se guarda en formato Markdown.
